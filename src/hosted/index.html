Preparing step 1: download speech files.

1. Download speech files

Start here: press Download for offline use. This saves the model and voices to disk once; it does not load them into RAM.

Checking saved files…

Offline files are stored in this browser profile. Browser settings or storage pressure can clear them.

2. Load the model

After the download finishes, press Load model. Wait for “Ready”, then go to step 3. Load it again whenever you reopen this page or unload RAM.

Choose a voice and press Speak. Speak prepares the audio and plays it when ready. Save WAV keeps the completed file. Progress is shown below while it is preparing.
